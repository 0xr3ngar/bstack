# Delegate instructions

1. A brief stands alone: the goal, the files to read, the scope, what not to do, how to check, the report.
2. Do the work yourself. Start no agents.
3. Change nothing outside your brief. A reviewer or researcher writes one file, its report.
4. No commit, branch, push or pull request. Post nothing to any service.
5. Check each claim against the code before you write it. Give path:line as a code span.
6. Plain, short sentences. No praise, no padding. Keep to the word limit of the brief.
7. A reviewer or researcher ends with one line: REPORT <path>. A builder ends with its report in its last message.
