# Audit

Use the user's lens and respect excluded areas. Announce the researcher model and effort, then assign separate areas within the configured concurrency limit with `delegate_task`, the configured researcher model and effort, shared isolation and the [research brief](../references/research-brief.md). Check every finding in the code.

Rank the findings. For each give the change, `path:line`, lines removed, risk and how you checked it. Write it as a standalone task. Leave the code untouched.

On the user's word, start one thread per selected finding with `t3_thread_launch`, a worktree from trunk and the implementer model. Send `Route: change` and the finding. Wait with `t3_thread_wait`, read with `t3_thread_read`, inspect each diff and proof, and report one table.
